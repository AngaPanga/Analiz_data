# Лабораторная №5. Выявление мошеннических транзакций

## Задание

Обучить и настроить бэггинг, случайный лес, LightGBM и CatBoost на
[creditcard.csv с Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud).
Цель — максимизировать **macro F1**. Для лучшей модели построить матрицу ошибок.
Код требуется опубликовать в Git-репозитории.

## Запуск

Проверено с Python 3.12. Файл `creditcard.csv` должен лежать рядом с `main.py`.
При переносе на другой ПК скачайте и распакуйте набор данных по ссылке выше
или перенесите имеющийся CSV. Само обучение работает без интернета, на CPU.

Из корня проекта:

```powershell
python -m pip install -r lab_5/requirements.txt
python lab_5/main.py
```

В текущем окружении проекта:

```powershell
.venv\Scripts\python.exe lab_5/main.py
```

Параметр `--no-show` отключает окна графиков, сохраняя PNG.
Параметры `--data путь_к_csv` и `--output папка` меняют пути.
Полный перебор обучает 24 ансамбля; запуск может занимать несколько минут.

## Файлы и алгоритм

| Файл | Назначение |
|---|---|
| `data.py` | Загрузка, проверка столбцов и значений, разделение 70/30 |
| `models.py` | Четыре модели и сетки параметров |
| `training.py` | Перебор параметров и выбор порога по macro F1 |
| `plots.py` | Диаграмма сравнения и матрица ошибок: чёрный фон, белый текст |
| `main.py` | Запуск эксперимента, сохранение результатов, вывод |

1. Признаки: `Time`, `V1`–`V28`, `Amount`; целевая переменная: `Class`.
   `Time` — время в секундах от первой транзакции, `Amount` — сумма транзакции.
   Класс 0 — легальная, 1 — мошенническая транзакция. Все признаки числовые;
   для деревьев масштабирование не требуется. Строки не удаляются.
2. `train_test_split(test_size=0.3, stratify=df.Class, random_state=42)`
   выделяет тест: 30% строк с сохранением долей классов с точностью до округления.
3. Из оставшихся 70% выделяются 25% для валидации, тоже со стратификацией.
   На ней проверяются базовые параметры и четыре комбинации для каждой модели.
4. Бэггинг усредняет деревья на случайных выборках с возвращением.
   Настраиваются глубина дерева и веса классов. Случайный лес дополнительно
   выбирает случайные признаки при разбиениях; настраиваются глубина и веса.
   У LightGBM подбираются число листьев и L2-регуляризация,
   у CatBoost — глубина и L2-регуляризация. Оба метода последовательно строят
   деревья, исправляя ошибки ансамбля.
5. Для каждой комбинации выбирается порог вероятности: класс 1 при `p >= порог`.
   Вероятности сортируются, накопленные числа TP/FP позволяют быстро проверить
   различные пороги. Выбирается максимум macro F1 на валидации.
6. Лучший вариант каждой модели заново обучается на всех тренировочных 70%.
   Порог фиксируется до оценки на тесте. На тесте вычисляются macro F1 при
   выбранном пороге и при стандартном 0.5 для той же обученной модели.
7. Среди четырёх моделей с двумя порогами выбирается максимальный тестовый
   macro F1 и строится матрица ошибок этого варианта.

**Macro F1 = (F1 класса 0 + F1 класса 1) / 2**, где
`F1 = 2 × precision × recall / (precision + recall)`.
Оба класса имеют одинаковый вес, несмотря на сильный дисбаланс.
Определение метрики: [документация scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.f1_score.html).

Тест не участвует в подборе параметров и порога. Выбор победителя по тесту
сделан для отчёта по условию задания; его результат не является независимой
оценкой всего процесса выбора моделей. Найден максимум в заданной сетке
на валидации, а не гарантированный глобальный максимум.

## Результаты

Папка `results` содержит:

- `split_counts.csv` — число транзакций каждого класса в выборках;
- `search_*.csv` — параметры, пороги и валидационные оценки всех вариантов;
- `parameters_*.json` — выбранные параметры моделей;
- `metrics.csv` — сравнение моделей на тесте;
- `classification_report.txt` — precision, recall и F1 лучшей модели;
- `model_comparison.png` — сравнение macro F1;
- `confusion_matrix.png` и `.csv` — матрица ошибок лучшей модели.

В матрице строки — истинные классы, столбцы — предсказанные.
В ячейках указаны количество и процент от истинного класса.

### Проверенный запуск

Всего 284 807 транзакций, из них 492 мошеннические. В тренировочной выборке
199 364 строки (344 мошеннические), в тестовой — 85 443 (148 мошеннических).

| Модель | Macro F1, подобранный порог | Macro F1, порог 0.5 |
|---|---:|---:|
| Бэггинг | 0.918305 | 0.916232 |
| Случайный лес | 0.930036 | **0.931118** |
| LightGBM | 0.927930 | 0.926852 |
| CatBoost | 0.918125 | 0.921519 |

Лучший результат — случайный лес при пороге 0.5. Улучшение на валидации
не гарантирует улучшения на тесте: поэтому приведены оба порога.
